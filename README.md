# 🎙️ Bangla VoiceTyper

**উইন্ডোজের যেকোনো অ্যাপ্লিকেশনে কণ্ঠে বাংলা টাইপ করুন!**

Bangla VoiceTyper হলো একটি **পেশাদার, সিস্টেম-ওয়াইড বাংলা ভয়েস টাইপিং** সফটওয়্যার। এটি ব্রাউজার, Microsoft Word, নোটপ্যাড—যেকোনো জায়গায় আপনার কণ্ঠে বলা বাংলা সঠিকভাবে **বাংলা ইউনিকোড**-এ টাইপ করে।

---

## ✨ প্রধান বৈশিষ্ট্য

| ফিচার | বিবরণ |
|---|---|
| **সিস্টেম-ওয়াইড টাইপিং** | যেকোনো উইন্ডোজ অ্যাপ্লিকেশনে টাইপ করে |
| **৩টি স্পিচ ইঞ্জিন** | Whisper (অফলাইন), Google (অনলাইন), Vosk (অফলাইন) |
| **বাংলা ইউনিকোড** | সম্পূর্ণ Unicode-ভিত্তিক, সঠিক বানান |
| **যুক্তবর্ণ সাপোর্ট** | স্বয়ংক্রিয় যুক্তবর্ণ (ক্ষ, ঙ্ক, ঙ্গ, ইত্যাদি) |
| **স্মার্ট বিরাম চিহ্ন** | কমা (,), দাঁড়ি (।), প্রশ্নবোধক (?) স্বয়ংক্রিয়ভাবে |
| **গ্লোবাল হটকি** | `Ctrl+Shift+B` দিয়ে যেকোনো জায়গা থেকে চালু/বন্ধ |
| **সিস্টেম ট্রে** | ব্যাকগ্রাউন্ডে চলে, স্ক্রিনে জায়গা নেয় না |
| **প্রফেশনাল GUI** | অডিও ভিজুয়ালাইজার, ইতিহাস, সেটিংস |

## 🚀 ইনস্টলেশন

### প্রয়োজনীয়তা
- Python 3.10 বা তার বেশি
- Windows 10 / 11

### ধাপ ১: প্রজেক্ট ক্লোন/ডাউনলোড
```bash
git clone <repo-url>
cd bangla_voice_typer
```

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### ধাপ ৩: Vosk মডেল (ঐচ্ছিক - অফলাইন মোডের জন্য)
```bash
# Vosk বাংলা মডেল ডাউনলোড করুন:
# https://alphacephei.com/vosk/models/vosk-model-small-bn-0.2.zip
# ফোল্ডারে unzip করে রাখুন:
mkdir %USERPROFILE%\vosk-models
# vosk-model-small-bn-0.2 ফোল্ডারটি এখানে রাখুন
```

### ধাপ ৪: চালু করুন
```bash
python main.py
```

## 📖 ব্যবহারবিধি

### দ্রুত শুরু
1. **সফটওয়্যার চালু করুন** — স্ক্রিনে একটি প্রফেশনাল উইন্ডো খুলবে
2. **🎤 রেকর্ড শুরু** বাটনে ক্লিক করুন (অথবা `Ctrl+Shift+B` চাপুন)
3. **বাংলায় কথা বলুন** — যেমন: "আজকের আবহাওয়া খুব ভালো"
4. টাইপ করার পরে অ্যাপটি স্বয়ংক্রিয়ভাবে পুনরায় শোনা শুরু করবে
5. **🖊️ এপ্লিকেশনে টাইপ করুন** বাটনে ক্লিক করলে টেক্সটটি যেকোনো অ্যাপে যাবে

### কীবোর্ড শর্টকাট
| শর্টকাট | কাজ |
|---|---|
| `Ctrl+Shift+B` | রেকর্ড চালু/বন্ধ টগল |
| `Ctrl+B` | পুশ-টু-টক (ধরে কথা বলা) |
| ট্রে আইকন | রাইট-ক্লিক করে মেনু |

### বৈশিষ্ট্য বিস্তারিত

#### স্পিচ ইঞ্জিন তুলনা
> **ডিফল্ট ইঞ্জিন: Google** (অনলাইন) — ভারী ডাউনলোড ছাড়াই দ্রুত ও নির্ভুল। Whisper/Vosk চাইলে সেটিংস থেকে বেছে নিন।

| ইঞ্জিন | Accuracy | গতি | অফলাইন | ইনস্টল |
|---|---|---|---|---|
| **Google** (ডিফল্ট) | ⭐⭐⭐⭐ | দ্রুত | ❌ | ডিফল্টে আছে |
| **Whisper (OpenAI)** | ⭐⭐⭐⭐⭐ | মাঝারি | ✅ | আলাদা (~2-3GB) |
| **Vosk** | ⭐⭐⭐ | খুব দ্রুত | ✅ | মডেল আলাদা |

#### বিরাম চিহ্ন স্বয়ংক্রিয় যোগ
সফটওয়্যারটি বাক্যের শেষে যতিচিহ্ন সঠিকভাবে বসায়:
- সাধারণ বাক্য → `বাক্যের শেষে দাঁড়ি (।)`
- প্রশ্নবোধক বাক্য → `বাক্যের শেষে প্রশ্নবোধক (?)`
- কমা/সেমিকোলনের স্থান অনুযায়ী ঠিক করে

## ⚙️ সেটিংস

সেটিংস প্যানেল থেকে আপনি করতে পারবেন:

- **ইঞ্জিন নির্বাচন**: Whisper / Google / Vosk
- **Whisper মডেল**: tiny / base / small / medium (অ্যাকিউরেসি vs গতি)
- **টাইপিং গতি**: দ্রুত / স্বাভাবিক / ধীর
- **হটকি কাস্টমাইজেশন**: যেকোনো শর্টকাট
- **অ্যাকসেন্ট রঙ**: অ্যাপের থিম রঙ বদলানো

সেটিংস স্বয়ংক্রিয়ভাবে সেভ হয় `%APPDATA%\BanglaVoiceTyper\config.json`-এ।

## 🗂️ প্রজেক্ট স্ট্রাকচার

```
bangla_voice_typer/
├── main.py                  # মেইন এন্ট্রি পয়েন্ট
├── requirements.txt         # ডিপেন্ডেন্সি
├── build.bat                # Windows exe বিল্ড স্ক্রিপ্ট
├── config/
│   ├── settings.py          # সেটিংস ম্যানেজার
│   └── default_config.json  # ডিফল্ট কনফিগ
├── core/
│   ├── audio_recorder.py    # মাইক্রোফোন রেকর্ডিং
│   ├── speech_engine.py     # স্পিচ রিকগনিশন (৩ ইঞ্জিন)
│   ├── bangla_processor.py  # বাংলা টেক্সট প্রসেসিং
│   └── keyboard_typer.py    # সিস্টেম-ওয়াইড টাইপিং
└── gui/
    ├── main_window.py       # প্রধান উইন্ডো
    ├── settings_dialog.py   # সেটিংস ডায়ালগ
    ├── audio_visualizer.py  # অডিও ভিজুয়ালাইজার
    └── system_tray.py       # সিস্টেম ট্রে
```

## 📦 এক্সিকিউটেবল তৈরি (Windows .exe)

```bash
build.bat
```

এতে একটি স্বতন্ত্র `BanglaVoiceTyper.exe` ফাইল তৈরি হবে `dist\` ফোল্ডারে, যা ইনস্টলেশন ছাড়াই চালানো যাবে।

> **দ্রষ্টব্য**: Google ইঞ্জিন ব্যবহারের জন্য ইন্টারনেট সংযোগ লাগবে। Whisper (অফলাইন) চাইলে আলাদা করে ইনস্টল করুন: `pip install openai-whisper` (আগের মতো অফলাইনে সেরা ফলাফল)।

## 🛠️ টেকনিক্যাল ডিটেইলস

- **ভাষা**: Python 3.10+
- **STT**: OpenAI Whisper (offline), SpeechRecognition (Google), Vosk
- **GUI**: PyQt6
- **টাইপিং**: pynput (সিস্টেম-লেভেল কিবোর্ড ইমুলেশন)
- **অডিও**: PyAudio, sounddevice
- **হটকি**: keyboard (গ্লোবাল হুক)
- **বিল্ড**: PyInstaller

### Python ইনস্টল করার পদক্ষেপ (যদি না থাকে)
1. [python.org](https://python.org) থেকে Python 3.10+ ডাউনলোড
2. ইনস্টল করার সময় **"Add Python to PATH"** চেক করুন
3. `python --version` দিয়ে যাচাই করুন
